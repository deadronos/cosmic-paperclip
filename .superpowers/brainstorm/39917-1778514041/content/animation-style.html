Smooth Number Transitions

Choose an animation style for the counters, rates, and progress elements

A

Ease-Out (Recommended)

Fast start, gentle finish. Numbers catch up quickly then settle. Feels responsive and natural.

B

Linear

Constant speed throughout. Predictable but can feel robotic.

C

Spring Physics

Overshoots slightly then settles. More playful, might be distracting for serious UI.

Duration

All animations should complete within 300–500ms. Numbers that are closer should animate faster than numbers that are far apart.
